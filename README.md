# On-Se-Bat-Pour-R-ussir---OSBPR-
OSBPR – On Se Bat Pour Réussir est une association créée en Mauritanie, dans la ville de Boghé, région du Brakna, avec l’engagement des élèves du lycée de Boghé. Notre objectif est de promouvoir l’éducation, la réussite scolaire, la motivation, la solidarité et l’entraide entre les jeunes.
